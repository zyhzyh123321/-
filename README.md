# 分子工坊

一个用 Python + PySide6 写的化学分子搭建沙盒：在平面画布上像搭积木一样把原子连起来，点一下「立起来看 3D」，程序就按真实的杂化态和力场把分子算成三维构型——你画的只是结构式，立体形状是算出来的。

本项目是网页版的 Python 桌面重写版，化学内核（`molecule_workshop/chem/`）不依赖界面，可以单独调用和测试。

---

## 1. 运行方式

```bash
cd 分子工坊
python run.py
```

- 入口就是 `run.py`，不需要安装、不需要编译。
- **依赖已在本机安装完毕，无需联网**：Python 3.14.3、PySide6 6.12.0（Qt 6.12.0）、numpy 2.4.4。
- 换机器或重装环境时再按 `requirements.txt` 安装即可。

## 2. 操作说明

### 2.1 放原子：从原子盘拖出来

**按住左侧原子盘里的元素按钮，拖到画布上松手** —— 这是放置原子的唯一方式。

- 落在空白处 → 就在那里生成一个原子
- 落在某个原子周围的**蓝点**附近 → 直接吸附成键，键长就是标准键长
- 落在**价键已满**的原子上 → 拒绝，并提示原因
- 拖动时会有一个半透明球跟着光标，提前告诉你落点行不行

> 右键画布空白处的「在此放置」也可以放原子。
> 左键在画布上**只做**拖动、选择、框选 —— 不会再意外放出一个原子。

### 2.2 四个工具（左侧工具栏，或按快捷键）

| 工具 | 快捷键 | 点原子 | 点空白 | 拖动 | 右键 |
| --- | --- | --- | --- | --- | --- |
| **鼠标**（默认） | `V` | 选中它 | 取消选择 | 拖原子 = 移动/旋转；拖空白 = **框选** | 上下文菜单 |
| **连键** | `B` | 记为连键起点 | — | 从蓝点拖到另一个蓝点 → 连键 | 取消当前起点 |
| **删除** | `D` | 删除该原子及其全部键 | — | 框选批量删除 | 删除该键 |
| **平移** | `Space` | — | — | 平移画布（不改任何坐标） | — |

> 「放置」工具已经删掉了：它和鼠标模式的职责重叠，正是「想选个原子结果又放了一个」
> 的根源。放原子现在只归原子盘管。

### 2.3 选择与右键菜单

| 操作 | 效果 |
| --- | --- |
| 左键点原子 | 选中（替换原来的选择） |
| 左键拖空白 | **框选**，框内的原子全部选中 |
| `Ctrl` + 左键点原子 | 多选：加入选择；再点一次则移出 |
| `X` / `Delete` | 删除**当前选中的**原子（没有选中时删鼠标指向的那个） |
| 右键 | 弹出菜单：选中两个原子可「成键」/「升降键级」/「删除」；点键时直接给出「改为双键 / 改为单键 / 删除这根键」；空白处可「在此放置」；底部还有撤销/重做 |

### 2.4 连键：从蓝点拖到蓝点

1. 按住一个原子周围的**蓝点**（那是它的空插槽）开始拖
2. 拖动过程中有一条**虚线**跟着光标；靠近另一个原子的蓝点时，虚线会**吸附过去**
   并高亮那个目标蓝点 —— 绿色表示能连，红色表示连不上（通常因为对方价键已满）
3. 松手 → 连成单键，并且**两端自动摆到标准键长**

> 为什么必须自动摆正：早先只要两个原子靠得够近就能连上，
> 于是 2D 结构里经常出现拉得很长或挤在一起的键，越拼越乱。
> 现在连完之后键长一定是标准值。

把连键拖到**已经相连**的原子上，则是把它们之间的键升一级。

### 2.5 拖动原子会发生什么

| 情况 | 结果 |
| --- | --- |
| **带键的原子**（未超阈值） | 绕相连的那个原子**整体旋转**：只改方向，**键长一丝不变**，身后的基团跟着一起转 |
| **没有键的原子** | 跟手自由移动，**拖到哪放到哪**（松手就停在那里） |
| 靠近某个空插槽 | 出现**虚线预览**并高亮目标插槽，松手**精确吸附**成键 |
| 拖过断键阈值（约 1.85 倍键长） | 键先变成**红色虚线**提示（此时还没断），**松手才真正断开**；原子停在当前位置，可以再拖去别处连 |
| 拖出去又拖回阈值内 | **取消断键**，键长恢复标准值 |
| 把两个已相连的原子**拖到一起** | 把键升一级（单 → 双 → 三） |

拖断键之后按一次 `Ctrl+Z`，**键和位置会一起恢复**。

### 2.6 改键级（双键 / 三键）

| 操作 | 效果 |
| --- | --- |
| **右键点那根键** | 菜单里直接选「改为双键 / 改为三键 / 改为单键」 |
| 鼠标悬在键上按 `+` / `-` | 升 / 降一级 |
| 选中两个原子后右键 | 同样可以升降它们之间的键 |

**升键会自动脱掉自动补上的氢。** 这是必须的：
乙烷补满氢后两个碳的插槽都是 0，不脱氢就永远升不了键 ——
也就是「双键根本做不出来」。现在把 C—C 升成双键会
**自动移除 2 个氢**，变成乙烯（提示里会说明移除了几个）。
玩家手动放的氢、以及其它重原子，一律不会被动。

> 降键**不会**自动补氢 —— 免得玩家没意识到结构被改了。

### 2.7 视图与历史

| 操作 | 效果 |
| --- | --- |
| 中键拖动 | 3D 视图里旋转视角；2D 平面里平移视图 |
| `Shift` + 中键拖动 | 平移视图（两种模式都可） |
| 滚轮 | 以光标为中心缩放 |
| 空格键 / 「立起来看 3D」 | 自动补氢并算出真实立体构型，切到 3D |
| 「重新编辑」 | 回到平面，原来的布局不会被打乱 |
| `Ctrl+Z` / 左侧「撤销」按钮 | 撤销（按钮上会显示还能撤销几步） |
| `Ctrl+Y` / `Ctrl+Shift+Z` / 左侧「重做」按钮 | 重做 |
| `H` / `G` | 显示/隐藏氢原子、参考网格 |

> 提示：3D 视图里最值得转一圈看的是环己烷（平面画法是六元环，真实形状是一把椅子）和乙炔（四个原子完全共线）。
>
> 窗口缩放：资料面板在窄窗口下会自动收起把空间让给画布（左侧「显示资料面板」可以强制展开）。
> **左侧栏的宽度是按当前字体算出来的，不会随窗口被压扁** —— 换显示缩放或换字体时它会自己变宽。

## 3. 2D 插槽的角度是怎么定的

2D 拼装**不追求与 3D 理想键角一致**，要的是「摆得开、点得中」。所以空插槽的角间距按**还能连几根键**决定：

| 还能连几根 | 角间距 | 形状 |
| --- | --- | --- |
| 4 根 | 90° | 十字形 |
| 3 根 | 60° | 三分 |
| 2 根 | 180° | 对开 |

三条规则：

1. **按可成键数定角间距**。一律用 60° 时，4 个空位刚好占满一圈，
   相邻两个碳的空位就会落到同一处 —— 拖动时表现为「氢原子叠在氢原子上」。
2. **空位只放在没有键的那一侧**（最宽的角度空档里），不会和已有的键挤在一起。
3. **相邻原子的空位互相避让**。绕满一圈的插槽会整体旋转一个相位，
   避开邻居的空位落点 —— 否则乙烷两个碳的空位落点会**完全重合**（实测距离 0.000 键长）。

另外，拖动时若同时够到多个候选，**优先选还有空插槽的原子**，哪怕它稍远一点。
这一条修掉了「拖到指定位置放不下去、被识别成连到了已经满了的碳」。

## 4. 化合价规则

每个元素有固定数量的**价键插槽**（在 `chem/constants.py` 里定义）：

| 元素 | 插槽数（化合价） |
| --- | --- |
| 碳 C | 4 |
| 氮 N | 3 |
| 氧 O | 2 |
| 氢 H | 1 |

连键时按**键级消耗插槽**：

- 单键消耗 **1** 个插槽；
- 双键消耗 **2** 个插槽；
- 三键消耗 **3** 个插槽。

所以碳有 4 个插槽，正好对应 4 根单键（甲烷 CH₄）；换成双键时就只剩 2 个位置给别的原子（乙烯 C₂H₄，每个碳接 2 个氢）；换成三键时就只剩 1 个位置（乙炔 C₂H₂，每个碳接 1 个氢）。插槽用满后不再接受新键——这套机制让「不饱和键」变得可见。

画布上原子周围的圆点就是它的插槽：**亮的还空着，暗的已经被占用**。
亮点的位置就是松手会吸附到的位置 —— 所见即所得。

## 5. 3D 是怎么算出来的

两段流水线：先搭理想骨架，再用**位置约束求解器**把几何精确收敛。

**第一段：杂化判定 + 骨架生成（`chem/geometry.py`）**

按每个原子参与的键判断杂化态，再由杂化态决定每根键的方向：

| 情况 | 杂化 | 几何形状 | 键角 |
| --- | --- | --- | --- |
| 有 1 个三键 | sp | 直线形 | 180° |
| 有 1 个双键 | sp² | 平面三角形 | 120° |
| 其余 | sp³ | 正四面体 | 109.47° |

键长取 `constants.py` 里的平衡键长。环**逐边按自己的目标键长**展开成多边形
（甲苯这类环上单双键交替的分子，长短边必须交替，不能用平均键长）。
环上原子的取代基单独摆放，并保证朝环**外**——
通用摆放算法只保证「与入边成理想角」，不区分朝里朝外，
曾经把苯环上的氢全塞进环内、和对面碳重叠。

**第二段：位置约束求解（`chem/relax.py`）**

用 PBD（Position-Based Dynamics）迭代：

1. 先把所有键角精确转到目标值
2. 再把所有键长精确拉到平衡值
3. 中间穿插软性的非键分离（权重很小，且做完立刻重新满足键长键角）

**约束是硬约束，按构造始终满足** —— 所以任何分子的键长偏差都是 0.0000 Å。

> 为什么不用力场梯度下降？
> 因为实测它不可靠：会把**本来完全正确的初始几何弄坏**。
> 苯的初始几何是键长偏差 0.0000 Å、内角全 120°、严格共面，
> 跑完梯度松弛后键长偏差变成 1.04 Å、内角散成 49°~73°。
> 原因是它用非键排斥换取了键长松弛：能量从 113 降到 44，
> 代价却是把键拉长到 2.5 Å —— 它优化的是能量，不是几何正确性。
>
> PBD 的冲突只会表现为「环被撑开一点」，而不会「键被拉断」。

**环己烷的椅式怎么来的**：初始摆成平面六边形（键长键角都满足），
但环碳是 sp³、想要 109.47°，而平面六边形内角是 120°。
求解器每轮都往 109.47° 拉一点，环于是自己皱起来 ——
这是真实的物理驱动，不是手塞进去的构象。

**小环不需要特殊照顾**：环丙烷内角只能是 60°，这是三条硬键长约束在三角形上的
必然结果，求解器自然收敛到 60.00°。
（曾经把环内角的目标改成 60°，结果环己烷失去了褶皱驱动力而变平 —— 见 `tools/ring_angle_study.py`。）

> 一句话：**原子的 3D 位置由结构算出来，不能由玩家随手拖动决定。**

## 7. 分子识别原理

识别分两级：**粗筛哈希** + **精确图同构**（`chem/identify.py`）。

1. **粗筛**：把分子化成「重原子骨架 + 每个重原子上的氢数」的图，用迭代 WL（Weisfeiler-Lehman）哈希加分子式算一个键，从内置库里捞出几条候选。哈希很快，但可能把不同分子算到同一个键上（误报），所以它只负责缩小范围。
2. **精确判定**：对候选逐条做真正的**图同构判定**（带回溯的搜索 + 节点预算上限），命中才算识别成功。

为什么不干脆做一个「完美规范串」？因为让字符串对同构不变其实很难——对称环、等价原子的先后顺序、标记编码都会踩坑。而识别根本不需要它：**正确性来自同构判定本身，而不是来自某个精巧的字符串。**

**所以同一个分子换个画法照样认得出**：识别只关心「谁和谁相连、键级是多少、每个重原子上挂几个氢」这张图，不关心你是从哪个原子开始画的、键画成什么角度、坐标摆在哪儿。苯环从任意一个碳起笔、单双键交替从哪一端开始，画出来都是同一张图，也就是同一个苯。

## 9. 已知边界

- **氮按 3 价建模**：氮只有 3 个插槽，所以硝基（—NO₂）这类高价态结构不在建模范围内，硝基化合物没有收录。
- **2D 与 3D 是两套几何**：2D 平铺时的插槽角度（90°/60°/180°）只为「摆得开、点得中」服务，
  与 3D 的理想键角（109.47°/120°/180°）**不是一回事**，也不要指望 2D 摆出来的角度有化学含义。
  真正的构型由「立起来」时的求解器算出来。
- **小环键角是几何必然**：环丙烷实测内角精确 60.0°、环丁烷 84.6°~95.4°，离 109.47° 差得很远。
  这不是算错了——三元环、四元环在几何上就做不到四面体键角，所以显示的是环张力导致的真实值。
- **环己烷的褶皱比真实值夸张**：实测环碳离平面 1.68 Å，而真实椅式约 0.25 Å。
  原因是本作没有二面角/扭转项去约束它，只有键长键角硬约束。观感是一把清楚的椅子，数值偏大。
- **2D 下第三个原子可以落在两个成键原子之间**：那是一根键长的位置，空间上不冲突，
  真实的三维里也不会重叠。2D 视图只保证平面内不叠原子。
- **升键时脱氢只针对"自动补的氢"**：手动一个个放上去的氢不会被自动删掉，
  插槽不够时会明确报错并让你自己删。这是刻意的 —— 自动删玩家亲手放的东西太粗暴。
- **"拖到一起升键"需要拖得比较近**：判定阈值是 0.9 倍键长（明显小于一个键距）。
  这样普通调方向不会误升键，但也不会让人拖半天没反应。
- **不做音效**：这是一个安静的沙盒。
- **左侧栏宽度是按字体算的**：写死宽度时「内容区可用宽」正好等于「最宽按钮宽」，
  余量为 0；只要字体大一点（125% 显示缩放、系统换字体）文字就会顶出按钮叠在一起。
  现在改成量字体算宽度（`side_panel.py` 的 `_apply_width`），窗口下限也跟着一起算。
  可用 `tools/check_sidebar_width.py` 在多种字体倍数下复验。
- **文本描述可能有个别不准**：每个分子的 `desc` / `use` / `note` 是人工撰写的科普文字，
  可能存在个别不准确之处；但**分子式与相对分子质量是由结构算出来的**，可以先信这两个。

### 无头环境下怎么自查界面

本机无法给浏览器/图形界面截图，所以界面验证走「离屏渲染出 PNG」这条路：

```bash
python tools/screenshot.py           # 跑真实主窗口，输出到 out/
python tools/check_geometry.py       # 打印各分子的键长偏差与环几何
python tools/ring_angle_study.py     # 环几何护栏，任何改动后都应「全部符合预期」
python tools/check_sidebar_width.py  # 字体放大 1~2.5 倍，侧栏都不能叠字
python tools/resize_probe.py         # 来回缩放窗口，左侧栏不能有重绘残留
```

> 看截图时注意：**文字类问题一定要按 1:1 原始分辨率看**。
> 缩略图会把相邻字形的像素混在一起，看起来像「文字重叠/错位」，
> 但原图其实是好的 —— 这个假象已经误导过好几轮排查。

## 11. 打包成 exe（可选）

```bash
python build_exe.py
```

`build_exe.py` 会检查 PyInstaller 是否可用，然后以 `run.py` 为入口，用 `--onefile --windowed` 打出单文件 exe（产物在 `dist/` 下）。

> **打包需要联网安装 pyinstaller**：如果本机没有 PyInstaller，脚本会打印安装命令并退出，不会硬着头皮往下跑。
